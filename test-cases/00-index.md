## How to Use

Each test case follows this format:
- **TC-XX.YY** — Unique identifier (file number.case number)
- **Precondition** — Setup required before testing (if any)
- **Steps** — Numbered actions to perform
- **Expected** — What should happen if the feature works correctly

Mark each test case as PASS/FAIL during QA execution. Note any bugs with screenshots and reproduction steps.
