# TC-30: Prompt Library

## TC-30.01: Open prompt library (Alt+L)
- **Steps:**
  1. Focus chat composer
  2. Press **Alt+L**
- **Expected:** Prompt library dialog opens.

## TC-30.02: Create prompt
- **Steps:**
  1. Click "Create Prompt"
  2. Enter name: "Code Review"
  3. Enter prompt text: "Please review this code for bugs and improvements..."
  4. Add tags: "review", "quality"
  5. Save
- **Expected:** Prompt created. Appears in library list.

## TC-30.03: List prompts
- **Steps:**
  1. Open prompt library
- **Expected:** All saved prompts listed with name and tags.

## TC-30.04: Update prompt
- **Steps:**
  1. Open an existing prompt
  2. Modify the text
  3. Save
- **Expected:** Prompt updated. Changes persisted.

## TC-30.05: Delete prompt
- **Steps:**
  1. Delete a prompt
- **Expected:** Prompt removed from library.

## TC-30.06: Insert prompt into composer
- **Steps:**
  1. Open prompt library
  2. Click on a prompt
- **Expected:** Prompt text inserted into the chat composer. Library closes.

## TC-30.07: Search/filter prompts
- **Steps:**
  1. Type in the prompt library search field
- **Expected:** Prompts filtered by name, text content, or tags.

## TC-30.08: Prompt with tags
- **Steps:**
  1. Create a prompt with multiple tags
  2. Browse by tags
- **Expected:** Tags displayed on prompt. Can filter by tag.
