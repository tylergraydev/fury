title: Usage Dashboard
description: Track token usage, costs, and trends across workspaces

The usage dashboard shows how many tokens you've used, what it costs, and how usage breaks down across workspaces and time periods.

## Opening the dashboard

Press <Tooltip tip="Ctrl+Shift+U on Windows/Linux">**Cmd+Shift+U**</Tooltip> to open the usage dashboard.

## Metrics tracked

| Metric | Description |
|--------|-------------|
| **Total cost** | Aggregate cost in USD |
| **Input tokens** | Tokens sent to the model |
| **Output tokens** | Tokens generated by the model |
| **Cache read tokens** | Tokens served from cache |
| **Cache creation tokens** | Tokens written to cache |
| **Turns** | Number of agent turns |
| **Duration** | Total time spent on agent turns |

## Time period filter

Filter data by:

- **Today** — Current day only
- **7 days** — Last week
- **30 days** — Last month (default)
- **All time** — Everything

## Workspace filter

Select a specific workspace from the dropdown to see its usage, or view all workspaces combined.

## Charts

### Cost over time

An area chart showing daily cost trends over the selected time period.

### Token breakdown

A stacked bar chart showing the mix of input, output, cache read, and cache creation tokens per day.

## Per-workspace breakdown

A table sorted by highest cost, showing each workspace's total cost, input/output tokens, number of turns, and last activity timestamp.
