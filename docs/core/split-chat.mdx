---
title: Split Chat
description: View two workspace chats side by side
---

Split chat lets you display two workspace conversations side by side, so you can monitor or compare agents working in parallel.

## Opening split chat

In the **file tab bar**, hover over a workspace's chat tab and click the **split icon** (two columns). The view splits into two resizable panes — your current chat on the left and the selected workspace's chat on the right.

## Using split chat

Each pane is fully independent:

- **Separate message histories** — Each pane shows its own workspace's conversation
- **Independent scrolling** — Scroll through each conversation separately
- **Send messages** — Type and send in either pane
- **Focus tracking** — Click a pane to give it keyboard focus (indicated by a blue border)

Keyboard commands like stopping the agent apply to whichever pane has focus.

## Resizing

Drag the divider between panes to adjust the split. Each pane has a minimum width of 20%.

## Closing split chat

Click the **split icon** again in the tab bar to return to the normal single-pane view. Split chat also closes automatically if the secondary workspace's tab is closed.

## Use cases

- **Monitor parallel agents** — Watch two agents work on related tasks
- **Compare approaches** — Run different prompts in two workspaces and compare results
- **Multi-repo workflows** — Work in one repo while monitoring progress in another
