title: Snippets
description: Save and reuse code snippets across workspaces
---

Snippets let you save frequently used code blocks for quick access. Insert them into the chat composer or copy them to the clipboard.

## Opening the snippet manager

Press <Tooltip tip="Ctrl+Shift+S on Windows/Linux">**Cmd+Shift+S**</Tooltip> to open the snippet manager dialog.

## Creating a snippet

1. Open the snippet manager
2. Click **New Snippet**
3. Fill in the fields:

| Field | Required | Description |
|-------|----------|-------------|
| **Title** | Yes | A descriptive name |
| **Code** | Yes | The code content |
| **Language** | No | Programming language (auto-detected if not set) |
| **Description** | No | Brief explanation |
| **Tags** | No | Comma-separated tags for categorization |

4. Click **Create**

Supported languages include: bash, c, cpp, css, go, html, java, javascript, json, kotlin, markdown, python, ruby, rust, sql, swift, typescript, and yaml.

## Using snippets

From the snippet manager:

- **Click a snippet** to insert its content into the chat composer
- **Hover and click the copy icon** to copy to clipboard

## Searching and filtering

The snippet manager provides:

- **Search** — Filter by title, description, content, language, or tags
- **Tag filter** — Click tag buttons to filter by specific tags

## Editing and deleting

- **Edit** — Hover over a snippet and click the pencil icon
- **Delete** — Hover over a snippet and click the trash icon
