Fury lets you run multiple AI coding agents in parallel, each in its own isolated workspace. Chat with Claude or Codex to write code, review diffs, run scripts, manage PRs, and track changes — all from a single desktop app.

## Key features

- **Multi-workspace** — Run isolated workspaces on separate git branches with full worktree isolation
- **Multiple agents** — Chat with Claude Code or OpenAI Codex CLI
- **Split chat** — View two workspace conversations side by side
- **Diff viewer** — Review code changes with inline diffs before merging
- **Integrated terminal** — Setup, run, and shell terminals powered by xterm
- **PR management** — Create, review, and merge pull requests without leaving the app
- **Test runner** — Auto-detect frameworks, run tests, track coverage and history
- **Checkpoints** — Save and revert conversation states at any point
- **Team view** — Monitor and broadcast messages to multiple agents at once
- **GitHub Actions** — View workflow runs, logs, and re-run failed jobs
- **Linear integration** — Search and link Linear issues to workspaces
- **Azure DevOps** — Pull requests, CI pipelines, and reviews with ADO repositories
- **GitHub Copilot** — Code completions in the built-in editor
- **Language servers** — LSP plugins for 11 languages with auto-detection
- **Usage dashboard** — Track token usage, costs, and trends across workspaces
- **Bookmarks** — Mark code locations with notes and color labels
- **Snippets & prompts** — Save reusable code blocks and prompt templates
- **Workspace templates** — Save and reuse workspace configurations
- **Custom themes** — Three built-in themes plus a full theme editor
- **Dev containers** — Run agents and terminals inside Docker containers
- **One-click containerization** — AI-generated devcontainer configs for any repo
- **Cross-platform** — macOS (Apple Silicon & Intel), Windows, Linux
